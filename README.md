# 面试档案 · 公开展示版

一个覆盖岗位准备、模拟练习、面试复盘与错题管理的求职工作台。

> 本仓库是经过隐私清理的作品集版本。公司、岗位、面试记录、回答、评分和日期均为虚构示例，不包含真实简历、联系方式、录音、转写文本、面试作业、账号或访问凭据。

## 产品问题

求职准备通常散落在招聘软件、文档、录音和聊天记录中，导致每次面试都像从头开始。面试档案以“岗位”为主线，把准备、练习、复盘和薄弱点串成闭环。

## 可以体验的功能

- 岗位看板：跟踪准备、投递和面试状态
- 岗位档案：集中呈现岗位摘要、匹配证据与轮次安排
- 模拟练习：依据概率和回答框架逐题练习
- 面试复盘：用五维评分、优势、改进项和下一步组织反馈
- 错题管理：沉淀高频薄弱点，而不是只收藏题目
- 候选人资料：展示能力标签与证据库的信息架构

## 原型与公开版的边界

私人原型包含用户登录、D1 数据库、文件存储、材料提取、录音转写和结构化 AI 分析。为保护隐私，公开版：

- 不要求登录，不连接私人数据库或文件存储
- 不调用任何真实 AI 接口，不需要 API Key
- 不提供简历、图片、PDF 或音频上传
- 访客输入只保留在当前页面内，刷新即清除
- 使用全新的 Git 历史，不继承私人项目的提交记录

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000` 即可体验。

## 技术栈

Next.js 16、React 19、TypeScript、响应式 CSS。
